# Core Beliefs

1. JobBot is local-first.
2. The active MVP recommends existing resumes; it does not generate custom resumes.
3. The application step is manual and external.
4. Years-of-experience fit is a core matching signal.
5. Job descriptions are targeting input; user-maintained resume metadata is the resume source of truth.
6. Discovery sources provide coverage, while canonical ATS/direct URL sources carry higher trust.
7. Archived plans and docs are historical reference, not active architecture.
